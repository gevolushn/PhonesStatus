Privacy Policy

PhonesStatus

Last updated: 11 September 2026 · Home · Українська

Summary

PhonesStatus is a Windows desktop application that runs entirely on the user's own computer. The developer operates no server, no database and no other infrastructure that your data could reach. All requests go directly from your computer to Google, with nothing in between.

What the application does

PhonesStatus compares the status of internal phone extensions between a spreadsheet and a PBX, and writes the phones' current IP addresses — obtained from a router on the user's own local network — back into that spreadsheet.

Google data accessed

After your explicit consent, the application requests a single scope:

  • https://www.googleapis.com/auth/spreadsheets — read and write access to Google Sheets.

Why write access is required. The application's core purpose is to write the discovered IP addresses into the spreadsheet, which read-only access cannot do. No narrower scope exists for this use case: drive.file is not applicable because it only covers files created by the application itself, whereas the spreadsheet is created by the user beforehand.

The application accesses only the single spreadsheet whose link the user enters in its settings. It does not request or receive any other Google data — Gmail, Drive, Contacts or Calendar.

How the data is used

Spreadsheet content is used solely to:

  • read extension numbers, statuses and MAC addresses from the columns you specify;
  • write discovered IP addresses into the column you specify;
  • display the result inside the application window.

The data is not used for advertising, profiling, model training, or any purpose unrelated to the functionality described above.

Data storage and retention

  • Spreadsheet content is never stored. It exists in memory only while the application is running and is discarded when it closes. It is not written to disk or anywhere else.
  • The Google refresh token is stored locally in the settings file on your own computer, encrypted with Windows DPAPI. The encryption key is tied to your Windows user account, so a settings file copied to another machine cannot be decrypted.
  • The developer has no access to this token or to your spreadsheet content.

Data sharing

No data is shared with anyone. The only party the application communicates with is Google itself, and only on your instruction. The application contains no intermediate servers, analytics, telemetry or usage tracking.

Google API Services User Data Policy

PhonesStatus's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at Google Account permissions — find PhonesStatus and select "Remove access". The application immediately loses the ability to read or modify your spreadsheets.

Data deletion

Since the developer stores none of your data, there is nothing to delete on the developer's side. To remove the locally stored token, use the "Reset" button in the application's settings or delete the data/settings.json file.

Children

The application is intended for workplace use and is not directed at children under 13.
